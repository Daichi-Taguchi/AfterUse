# RiverGuard System Dynamics (PySD)

## Files
- `riverguard_model.mdl`: Vensim model
- `riverguard_sd_analysis.py`: simulation, plotting, report generation
- `requirements.txt`: Python dependencies
- `outputs/`: generated charts

## Setup
```bash
cd RiverGuard/system_dynamics
python -m pip install -r requirements.txt
```

## Run
```bash
python riverguard_sd_analysis.py
```

- `outputs/recycling_impact.png`
